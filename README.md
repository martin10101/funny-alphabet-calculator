# funny-alphabet-calculator

## Idea

TEST BUILD: A funny alphabet calculator. Instead of numbers, it uses letters. Show the chain: A + A = B, B + B = BB, BB + BB = BBB, BBB + BBB = BBBB, etc. Make it a simple web page with an input where I can type something like 'BB + BB' and get 'BBB'.

## How to use

- Open `index.html` (double-click it).
- Type an expression like `BB + BB` and press Calculate.

## Examples

- `A + A = B`
- `B + B = BB`
- `BB + BB = BBB`
