# Technology Stack: Funny Alphabet Calculator

## 1. Core Technologies
- **HTML5:** Semantic structure for the calculator interface.
- **CSS3:** Styling according to the "Serious Calculator" aesthetic, utilizing Flexbox/Grid for layout and CSS transitions for interactivity.
- **Vanilla JavaScript (ES6+):** Core logic for expression parsing, alphabet arithmetic, and DOM manipulation.

## 2. Development & Tools
- **Browser APIs:** Focus on standard DOM APIs for compatibility.
- **Git:** Version control for tracking development and logic changes.

## 3. Deployment
- **Static Hosting:** The project is designed to be hosted on any static file server (e.g., GitHub Pages, Netlify, Vercel).
