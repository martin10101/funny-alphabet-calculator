# Product Guidelines: Funny Alphabet Calculator

## 1. Voice & Tone
- **Absurdist Humor:** The language should treat the nonsensical alphabet arithmetic with absolute, unwavering seriousness.
- **Supportive but Confused:** Error messages should be polite but reflect a world where these calculations are the standard (e.g., "Error: 'C' is not a valid component for this tier of logic yet.").
- **Clarity in Chaos:** Despite the funny nature, instructions on how to use the input should be crystal clear.

## 2. Visual Identity
- **The "Serious Calculator" Aesthetic:** The UI should mimic high-end scientific calculators or financial software from the late 90s.
- **Color Palette:**
    - Primary: Office Gray (#D1D1D1)
    - Secondary: LCD Green (#9DBF9E)
    - Accents: Dark Charcoal (#333333) for text.
- **Typography:** Use monospaced fonts (like `Courier New` or `Roboto Mono`) to emphasize the "computational" nature of the tool.

## 3. Interaction Principles
- **Satisfying Clicks:** Buttons should have a distinct, slightly exaggerated tactile feel (css shadows and transforms).
- **LCD Display Effect:** Results should appear as if on an old-school liquid crystal display, perhaps with a slight flicker or fade-in.
- **Immediate Gratification:** There should be no "loading" states for these simple operations; the absurdity works best when it's snappy.

## 4. Brand Messaging
- "The Alphabet Calculator: Logic, but sillier."
- "Stop using numbers. Start using letters. It makes exactly as much sense."
